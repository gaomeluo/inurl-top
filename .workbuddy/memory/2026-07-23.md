## 连接结论（22:5x，已穷尽探测）
- 服务器公网 `167.179.111.144:22` 从本机**直连超时**（不可达）。
- 本机 tunnel 端口 14013–14023 接受 TCP 但**在 SSH 握手阶段被重置**（Connection established 后 kex 中止）——典型“本地转发已起、但上游到服务器那段没真正连上/已断”的表现。SOCKS5 握手被拒、HTTP-CONNECT 无响应/中止，全 38 个监听端口无一返回 SSH 横幅。
- **关闭 sandbox 重测结果完全一致** → 非沙箱隔离问题，而是：本环境确实到不了你的服务器，且你“调出来”的隧道其上游当前并未真正桥接到服务器。
- 因此：我**无法从这里直连下载**。继续盲探无意义。
- 推荐落地路径（也是 export-typecho.sh 原本的设计）：**你在自己能 SSH 的那侧**跑 `bash scripts/export-typecho.sh` → 拿到 `/root/inurl_top_backup_<日期>.tar.gz` → 下载后把 `typecho.sql` + `usr/uploads/` 交给我 → 我本地转换+构建。这样彻底绕开“隧道到我这里”的死结。
